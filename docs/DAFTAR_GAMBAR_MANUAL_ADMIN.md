# Daftar Gambar User Manual Admin SPL

Dokumen ini menjadi acuan pengumpulan tangkapan layar untuk user manual role admin proyek SPL (Survey Pengguna Lulusan). Semua gambar harus berasal dari aplikasi SPL ini, bukan dari proyek lain.

## Ketentuan Tangkapan Layar

1. Simpan semua gambar dalam format PNG langsung di folder `docs`.
2. Gunakan lebar viewport yang sama, disarankan 1440 px, dengan zoom browser 100%.
3. Sebaiknya gunakan fitur tangkapan layar seluruh halaman (`full page`) untuk halaman panjang. Gambar akan dipotong saat dimasukkan ke manual.
4. Pastikan sidebar, judul halaman, dan tombol utama terlihat.
5. Gunakan data contoh yang wajar. Jangan menampilkan password, token, atau data pribadi sensitif.
6. Halaman tabel sebaiknya berisi minimal tiga baris agar fungsi halaman terlihat jelas.
7. Dashboard, laporan, dan arsip harus berisi data agar grafik, statistik, dan hasil tidak kosong.
8. Nama file harus sama dengan kolom `Nama file` berikut.
