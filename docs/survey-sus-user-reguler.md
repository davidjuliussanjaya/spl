# Survey System Usability Scale (SUS) - User Reguler

## Tujuan Survey

Survey ini digunakan untuk mengukur tingkat kemudahan penggunaan website dari sudut pandang user reguler, yaitu pihak pimpinan atau petinggi kampus yang mengakses website untuk melihat informasi dan ringkasan data pada dashboard.

## Petunjuk Pengisian

Berikan penilaian terhadap setiap pernyataan berdasarkan pengalaman Anda saat menggunakan website.

Gunakan skala berikut:

| Skor | Keterangan |
| --- | --- |
| 1 | Sangat Tidak Setuju |
| 2 | Tidak Setuju |
| 3 | Netral |
| 4 | Setuju |
| 5 | Sangat Setuju |

## Daftar Pertanyaan

1. Saya merasa akan sering menggunakan website ini untuk melihat informasi dan ringkasan data kampus.

2. Saya merasa website ini terlalu rumit untuk digunakan.

3. Saya merasa website ini mudah digunakan saat mengakses dashboard.

4. Saya merasa membutuhkan bantuan teknis dari orang lain untuk dapat menggunakan website ini.

5. Saya merasa informasi yang disajikan pada dashboard sesuai dengan apa yang saya butuhkan.

6. Saya merasa terdapat banyak ketidakkonsistenan pada tampilan atau alur penggunaan website ini.

7. Saya merasa sebagian besar pimpinan atau petinggi kampus dapat mempelajari penggunaan website ini dengan cepat.

8. Saya merasa website ini membingungkan saat digunakan untuk melihat informasi pada dashboard.

9. Saya merasa percaya diri menggunakan website ini untuk memantau informasi yang tersedia.

10. Saya perlu mempelajari banyak hal terlebih dahulu sebelum dapat menggunakan website ini dengan baik.

## Catatan Perhitungan Skor SUS

Untuk pertanyaan bernomor ganjil, skor dihitung dengan rumus:

`nilai jawaban - 1`

Untuk pertanyaan bernomor genap, skor dihitung dengan rumus:

`5 - nilai jawaban`

Jumlahkan seluruh hasil skor, lalu kalikan dengan 2,5 untuk mendapatkan nilai akhir SUS.

`total skor x 2,5 = skor SUS`
