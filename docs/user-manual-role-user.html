User Manual
Role User Biasa

Panduan penggunaan Sistem Tracer Study untuk memahami menu, dashboard, profil akun, dan akses pengisian survey.

Aplikasi: Sistem Tracer Study dan Evaluasi Lulusan

Role: Regular User / User Biasa

Versi Dokumen: 1.0

Tanggal: 25 Juni 2026

1. Tujuan Manual

Manual ini dibuat untuk membantu pengguna dengan role user biasa memahami fungsi yang dapat diakses pada Sistem Tracer Study. Role user biasa memiliki akses terbatas dibanding admin, sehingga fokus penggunaannya adalah melihat ringkasan dashboard, mengelola profil akun, keluar dari sistem, dan memahami alur akses survey melalui kode.

2. Ruang Lingkup Role User Biasa

Fungsi Keterangan
Dashboard Melihat ringkasan hasil evaluasi lulusan, statistik, grafik, feedback, dan tabel tingkat kepuasan.
Filter Dashboard Menyaring data berdasarkan periode, fakultas, dan program studi.
Profil Saya Memperbarui nama, email, password, dan melihat informasi role akun.
Keluar Mengakhiri sesi login dengan aman.
Akses Survey Mengisi survey menggunakan kode akses yang diberikan, tanpa perlu masuk sebagai admin.
Catatan: Menu seperti Survey, Lulusan, Pengguna Lulusan, Pertanyaan, Aspek Evaluasi, Cetak Laporan, dan Arsip Survey hanya tampil untuk role admin.

3. Login ke Sistem

  1. Buka halaman login Sistem Tracer Study.
  2. Pilih tab Login Admin pada halaman awal.
  3. Masukkan email dan password akun user biasa.
  4. Centang Ingat Saya jika menggunakan perangkat pribadi.
  5. Klik tombol Masuk ke Dashboard.
Keamanan: Jangan menggunakan fitur Ingat Saya pada komputer umum atau perangkat yang dipakai bersama.

4. Mengenal Tampilan Utama

4.1 Sidebar

Sidebar berada di sisi kiri halaman. Untuk user biasa, menu utama yang ditampilkan adalah Dashboard. Pada layar kecil, sidebar dapat dibuka atau ditutup melalui ikon menu di bagian atas.

4.2 Navbar

Navbar berada di bagian atas halaman. Area ini memuat ikon notifikasi, nama pengguna, role akun, menu profil, dan tombol keluar.

4.3 Menu Akun

Klik area nama atau avatar pengguna di kanan atas untuk membuka menu akun. Dari menu ini pengguna dapat membuka Profil Saya atau memilih Keluar.

5. Menggunakan Dashboard

Dashboard menampilkan ringkasan performa dan kualitas lulusan berdasarkan data survey yang sudah terarsip.

Komponen Dashboard Fungsi
Lulusan Dinilai Menampilkan jumlah lulusan yang sudah memiliki data penilaian.
Indeks Kepuasan Menampilkan rata-rata skor kepuasan pengguna lulusan dari skala 4.00.
Kategori Terbaik Menunjukkan kategori kompetensi dengan skor tertinggi.
Kategori Terendah Menunjukkan kategori kompetensi dengan skor terendah untuk bahan evaluasi.
Grafik Program Studi Menampilkan jumlah responden berdasarkan program studi.
Grafik Penilaian per Kategori Menampilkan rata-rata penilaian tiap kategori kompetensi.
Umpan Balik Terbaru Menampilkan komentar atau masukan terbaru dari pengisi survey.
Tingkat Kepuasan Pengguna Menampilkan persentase penilaian Sangat Baik, Baik, Kurang, dan Sangat Kurang.

6. Menggunakan Filter Dashboard

  1. Pada bagian atas dashboard, cari area Filter.
  2. Pilih satu atau beberapa Periode yang ingin ditampilkan.
  3. Pilih Fakultas jika ingin membatasi data pada fakultas tertentu.
  4. Pilih Program Studi jika ingin melihat data yang lebih spesifik.
  5. Klik tombol Terapkan untuk menampilkan hasil filter.
  6. Gunakan tombol reset berbentuk tanda silang jika ingin kembali ke semua data.

Filter yang sedang aktif akan ditampilkan sebagai label kecil di bawah area filter. Ini membantu pengguna mengetahui data apa yang sedang dibaca.

7. Membaca Grafik dan Feedback

7.1 Grafik Ringkas

Dashboard hanya menampilkan beberapa data teratas agar tampilan tetap ringkas. Klik Lihat Selengkapnya untuk membuka grafik dalam tampilan lebih besar.

7.2 Umpan Balik

Bagian Umpan Balik Terbaru menampilkan tiga komentar terbaru. Klik Lihat Semua untuk melihat seluruh feedback yang tersedia.

8. Mengelola Profil Saya

  1. Klik nama atau avatar pengguna di kanan atas.
  2. Pilih menu Profil Saya.
  3. Pada bagian Informasi Profil, ubah nama lengkap atau alamat email jika diperlukan.
  4. Klik Simpan Perubahan.
  5. Pada bagian Ubah Password, isi password saat ini, password baru, dan konfirmasi password baru.
  6. Klik Perbarui Password untuk menyimpan password baru.
Perhatian: Fitur Hapus Akun bersifat permanen. Gunakan hanya jika benar-benar diperlukan dan sudah memahami risikonya.

9. Mengisi Survey dengan Kode Akses

Selain login sebagai user biasa, halaman awal sistem menyediakan tab Akses Survey. Fitur ini digunakan oleh responden yang menerima kode akses survey.

  1. Buka halaman awal Sistem Tracer Study.
  2. Pilih tab Akses Survey.
  3. Masukkan kode akses yang diberikan oleh pengelola survey.
  4. Klik Mulai Survey Sekarang.
  5. Periksa informasi lulusan dan data perusahaan yang tampil.
  6. Lengkapi data perusahaan, data pengisi, dan jawaban survey.
  7. Kirim survey setelah semua pertanyaan wajib sudah terisi.
Catatan: Kode akses hanya berlaku untuk survey yang aktif dan belum selesai diisi. Jika kode tidak valid, hubungi pengelola sistem.

10. Keluar dari Sistem

  1. Klik nama atau avatar pengguna di kanan atas.
  2. Pilih menu Keluar.
  3. Pastikan halaman kembali ke halaman awal atau halaman login.

Selalu keluar dari sistem setelah selesai menggunakan aplikasi, terutama jika memakai perangkat bersama.

11. Kendala yang Sering Terjadi

Kendala Penyebab Umum Solusi
Tidak bisa login Email atau password salah. Periksa kembali email dan password. Jika masih gagal, hubungi admin.
Menu admin tidak muncul Akun menggunakan role user biasa. Ini normal. Menu pengelolaan data hanya tersedia untuk admin.
Dashboard kosong Belum ada data survey sesuai filter. Reset filter atau pilih periode/fakultas/program studi lain.
Kode survey tidak valid Kode salah, survey tidak aktif, atau survey sudah selesai. Periksa kode akses dan hubungi pengelola survey.
Gagal ubah password Password saat ini salah atau konfirmasi password baru tidak sama. Isi ulang password dengan benar dan pastikan konfirmasi sesuai.

12. Ringkasan Hak Akses

Role user biasa digunakan untuk membaca informasi dan melakukan pengelolaan akun pribadi. Pengguna tidak dapat menambah, mengubah, atau menghapus data master seperti survey, lulusan, pengguna lulusan, pertanyaan, kategori, laporan, atau arsip survey.

Dokumen ini disusun berdasarkan menu dan route aplikasi pada Sistem Tracer Study Universitas Dinamika.
